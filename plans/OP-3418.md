## Guardrails

- **GPG signing mandatory** — user global CLAUDE.md: never use `--no-gpg-sign`. If
  signing fails, diagnose gpg-agent / pinentry-mode, don't bypass.
- **No scope creep** — this ticket is dependency freshness ONLY. No workflow migrations,
  no code cleanup, no Go version changes. Resist the urge to "while I'm in here…".
- **Public API surface is sacred** — this is a shared SDK. If any bump transitively
  exposes a changed type through the public `pkg/` API (e.g., `pq.Array` signature
  change bleeding through `cast.go`), stop and discuss. Consumer ripple > convenience.
- **Testify failures are the canary** — if `go test ./...` breaks, root-cause in the
  testify 1.10 → 1.11 changelog before patching call sites. Don't paper over behavior
  changes.
- **Branch naming verified** — `feature/OP-3418_dependency-updates-stg-sdk-golang`
  matches repo convention (`feature/*` per repo CLAUDE.md).
